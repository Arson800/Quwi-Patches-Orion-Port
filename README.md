# Quwi-Patches-Orion-Port
Not [the official](https://github.com/quwi26/Quwis-Patches) Quwi Patches repo, this is a fanmade port to the Orion Store by me.

## What does this Orion Port do ?

It makes it easier for people to quickly download the patch, instead of having to wait for Morphe to patch the APK.

## Is this the official Orion port for Quwi l's Patches?

No, it isn't, go [check out](https://github.com/quwi26/Quwis-Patches) the original repo and support the creator.

## Does this allow for online multiplayer cheating ?

No, Quwis plugin specifically disables all functions related to Stockfish during an online match; Cheating is impossible in this scenario.
